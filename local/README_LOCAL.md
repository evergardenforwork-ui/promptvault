# 🚀 PromptVault — Руководство по локальному запуску и деплою (Offline & Standalone Guide)

> **Для пользователей и друзей**: Как запустить PromptVault на любом компьютере с Windows, macOS или Linux за 1 минуту без интернета, без настройки баз данных и без регистрации в Supabase.

---

## ⚡ Быстрый старт в 1 клик (Windows 11 / 10)

1. Убедитесь, что установлен [Node.js](https://nodejs.org/) (версия 18, 20 или новее).
2. Дважды кликните по файлу **`start_promptvault.bat`** в корневой папке проекта (или `local/start_local.bat`).
3. Скрипт автоматически:
   - Проверит наличие Node.js.
   - Установит зависимости (`npm install`), если запускается впервые.
   - Запустит локальный сервер на SQLite (`data/promptvault.db`).
   - Автоматически откроет браузер по адресу: **`http://localhost:3000`**.

---

## 💻 Быстрый старт через Терминал (macOS / Linux / Windows)

```bash
# 1. Перейдите в папку проекта
cd path/to/promptvault

# 2. Установите зависимости (только при первом запуске)
npm install

# 3. Запустите локальный сервер
npm run dev
```

После этого откройте браузер: **`http://localhost:3000`**.

## 📦 Как перенести данные (Импорт и Экспорт)

### 📥 1. Как загрузить данные, переданные вам (Импорт)
1. Поместите полученный `.zip` файл в папку `local/backups/` (или оставьте в загрузках).
2. В интерфейсе PromptVault нажмите кнопку **«Импорт бэкапа»** в правом верхнем углу (или в сайдбаре).
3. Выберите `.zip` архив.
4. Все карточки, промпты, скиллы, команды, закладки и **реальные фотографии** сразу появятся в приложении!

### 📤 2. Как передать свои материалы другу (Экспорт)
- **Экспорт всей базы**:
  - Нажмите **«Экспорт бэкапа»** в шапке сайта.
  - Скачается полный ZIP-архив со всеми данными и фото.
- **Экспорт конкретного рабочего пространства (например, «1С»)**:
  - Откройте меню редактирования пространства (клик на шестерёнку/карандаш в сайдбаре).
  - Нажмите кнопку **«Экспорт в ZIP»**.
  - Скачается архив только с материалами этого пространства (без ваших личных материалов из других разделов).

## 🗄️ Где хранятся локальные файлы?

- **База данных**: `data/promptvault.db` (SQLite с поддержкой WAL-журналирования).
- **Загруженные фото и скриншоты**: `data/uploads/images/`.
- **Загруженные ZIP-пакеты скиллов**: `data/uploads/packages/`.
- **Папка для архивов**: `local/backups/` и `local/exports/`.

---

## 🛡️ Безопасность и Offline-режим

- Локальная версия работает **полностью автономно без интернета**.
- ИИ-функции (AI Smart Parser): если в файле `.env` не указан `GEMINI_API_KEY`, приложение работает стабильно и безопасно отключает вызовы ИИ с понятным предупреждением.
- Пароли хранятся в зашифрованном виде (`bcryptjs` хэши).
- Папка `data/` добавлена в `.gitignore`, поэтому ваша база данных и личные фото никогда случайно не попадут в Git.

# Plan: Добавление Файловой Системы, Пакетов Скиллов и ZIP Архивов

> Этот документ определяет подробный план реализации встроенной файловой системы и работы с пакетами промптов, .md файлами и .ZIP архивами в PromptVault.

---

## 🎯 Задачи и Цели

1. **Загрузка и парсинг .ZIP архивов**:
   - При создании/редактировании промпта можно перетащить (Drag & Drop) или выбрать `.zip` архив.
   - Сервер/клиент автоматический распаковывает его структуру (например, `skills/prompt/SKILL.md`, `agents/config.json`).
   - Исходный `.zip` файл загружается в Supabase Storage (бакет `prompt-files`).
   - Распарсенное дерево файлов сохраняется в Postgres поле `file_structure` (JSONB).

2. **Интерактивный Файловый Эксплорер (UI Tree View)**:
   - В режиме просмотра карточки промпта появляется вкладка **"📁 Файлы и Скиллы"**.
   - Отображение дерева файлов с иконками (`.md`, `.json`, `.ts`, папки).
   - Выбор любого файла открывает встроенный **Markdown/Code Viewer** с подсветкой синтаксиса и кнопкой "Скопировать содержимое".

3. **Скачивание и Экспорт**:
   - **Кнопка "Скачать ZIP целиком"**: Скачивает весь оригинальный архив.
   - **Кнопка "Скачать отдельный файл / ветку"**: Генерирует скачивание выбранного `.md` файла или подпапки на лету (используя `JSZip`).

---

## 🗓️ Этапы реализации (Roadmap)

### 🔹 Этап 1: Обновление типов (`src/types.ts`)
- Добавление типа `FileNode` для древовидных структур:
  ```typescript
  export interface FileNode {
    name: string;
    path: string;
    type: 'file' | 'directory';
    content?: string; // Текст md/json файла
    children?: FileNode[];
  }
  ```
- Добавление в интерфейс `Prompt` полей `filePackageUrl?: string` и `fileStructure?: FileNode[]`.

### 🔹 Этап 2: Компонент `FileTreeViewer.tsx` (Frontend)
- Построение интерактивного дерева файлов в стиле VS Code/GitHub.
- Поддержка клика по файлам `.md` с отображением форматированного Markdown.
- Кнопки быстрых действий:
  - 📋 Скопировать текст файла
  - 💾 Скачать отдельный `.md` файл
  - 📦 Скачать весь ZIP-пакет

### 🔹 Этап 3: Модуль парсинга ZIP на клиенте / бэкенде (`JSZip`)
- Подключение библиотеки `jszip`.
- Функция `parseZipFile(file: File)`:
  - Извлекает дерево папок и тексты всех `.md`/`.json` файлов.
  - Подготавливает структуру `FileNode[]` для отправки в Supabase.

### 🔹 Этап 4: Загрузка в Supabase Storage (`prompt-files`)
- Интеграция с бакетом `prompt-files` в Supabase Storage.
- Автоматическая генерация публичных ссылок для скачивания оригинальных `.zip` архивов.

## 🔮 Модель данных (JSONB в `prompts`)

Пример поля `file_structure`:
```json
[
  {
    "name": "skills",
    "path": "skills",
    "type": "directory",
    "children": [
      {
        "name": "prompt",
        "path": "skills/prompt",
        "type": "directory",
        "children": [
          {
            "name": "SKILL.md",
            "path": "skills/prompt/SKILL.md",
            "type": "file",
            "content": "# Prompt Skill Guidance\n..."
          }
        ]
      }
    ]
  }
]
```

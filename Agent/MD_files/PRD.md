## Executive Summary

PromptVault — персональное fullstack веб-приложение для хранения, организации и повторного использования промптов для нейросетей (Midjourney, DALL-E, Stable Diffusion, ChatGPT и др.), а также пакетов скиллов, субагентов и MCP (Skills & Agent Hub), репозиториев и AI-инструментов (Git Hub), быстрых команд (AI Commands) и закладок веб-сайтов (Web Bookmarks Hub). Ориентировано на частных пользователей и команды, которым нужен удобный «банк» проверенных материалов с визуальным результатом, встроенным просмотрщиком и редактором файлов, мультимодальным AI-парсером и поддержкой подсказок для ИИ.

## Core Goals & Objectives

- Предоставить единое место хранения промптов с поддержкой изображений (ДО/ПОСЛЕ и др. макеты)
- Обеспечить быстрый поиск и фильтрацию по категориям, типам, принадлежности, избранному и хештегам
- Предоставить полноэкранное пространство скиллов (SkillSpaceView) с файловым деревом, inline-редактором и подсказками
- Реализовать многопользовательский режим с разделением приватных/публичных материалов, рабочими пространствами (Workspaces) и личным избранным
- Обеспечить мгновенный мультимодальный парсинг ссылок, описаний и скриншотов через Gemini 3.1 Flash-Lite AI Smart Parser

## Target Users & Audience

**Основной пользователь**: Алексей (evergardenforwork@gmail.com) — администратор и основной контрибьютор контента. Использует продукт ежедневно для хранения собственных и найденных промптов, скиллов, инструментов, команд и закладок.

**Вторичные пользователи**: Другие зарегистрированные пользователи, которые просматривают публичные материалы и создают свои приватные коллекции.

**Боли**: Промпты теряются в заметках/чатах; нет визуальной привязки результата к промпту; сложно повторить хороший результат; неудобно хранить и передавать сложные пакеты скиллов/агентов; сложно структурировать инструменты и закладки.

## Problem Statement

Нет удобного инструмента, который позволяет хранить промпт вместе с его визуальным результатом (фото ДО/ПОСЛЕ), скиллы вместе с их файловой структурой, организовывать по категориям и бесконечным папкам, быстро находить и делиться с другими — без использования сторонних сложных сервисов.

## MVP Features

- [x] Авторизация (email + password, Supabase `users` table / SQLite, bcrypt)
- [x] **💼 Рабочие пространства (Workspaces)**: изолированные под-профили (1С, Дизайн, Личное и т.д.) с переключением на лету
- [x] **🎨 Dual Theme Engine**: переключение тем ☀️ Светлая (shadcn Paper) / 🌙 Тёмная (ThoughtLab Obsidian)
- [x] **🚀 Dual-Engine Backend**: Cloud Supabase (PostgreSQL + Storage) ИЛИ офлайн Local SQLite (`promptvault.db` + `uploads/`)
- [x] Админ-панель (UsersSection.tsx: CRUD пользователей, смена пароля)

- [x] Пакеты скиллов / Skill Space View (полноэкранный VS Code-подобный просмотрщик файлов)

- [x] Skill Hints — подсказки-промпты к скиллам (быстрое копирование)
- [x] Личное избранное во всех 5 разделах (per-user через `user_favorites` table)
- [x] Категории и хештеги
- [x] Фильтрация принадлежности: Все (+ чужие), Все мои, Мои (Авторские), Мои (Из сети), Чужие (Публичные)
- [x] Публичные/приватные материалы
- [x] Кроппер изображений (HTML5 Canvas)
- [x] 6 layout-макетов изображений
- [x] Экспорт и генерация кастомных ZIP архивов на лету (включая Full-Media Backup)
- [x] **🐙 Git Hub & AI Tools**: каталог репозиториев, моделей, агентов + 🪄 Gemini 3.1 AI Smart Parser (мультимодальный ввод до 4 скриншотов + URL + текст)
- [x] **⚡ AI Commands & Workflows**: каталог сниппетов, смарт-параметры `{{param}}`, привязка к скиллам
- [x] **🌐 Web Bookmarks & Sites**: каталог закладок с бесконечной древовидной структурой папок и подпапок, авто-Favicon
- [x] Gemini ИИ-ассистент (чат в контексте промпта + анализ фото) — ⏳ временно отключён

## Deployment Strategy

- **Dev**: `npm run dev` → `tsx server.ts` → Express + Vite dev server на порту 3000
- **Prod (Vercel)**: `npm run build` → Vite собирает `dist/`, Vercel деплоит `api/index.ts` как Serverless Function
- **Хостинг**: Vercel (основной), резерв — Render.com
- **Секреты**: `.env` файл (не в git), переменные в Vercel Dashboard

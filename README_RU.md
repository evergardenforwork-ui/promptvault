# PromptVault

PromptVault — это ваше личное хранилище промптов для нейросетей с интегрированным ИИ-ассистентом (Gemini), поддержкой многопользовательского режима, изоляцией чатов, гибкими макетами изображений и встроенным визуальным редактором-кроппером.

## 📂 Архитектура и структура проекта

Проект представляет собой современное fullstack веб-приложение:

- **Frontend**: React 19, Vite, Tailwind CSS v4 (для современной и быстрой стилизации), Framer Motion / Motion.
- **Backend / API**: Express.js (`server.ts`) для локальной разработки и раздачи статики в production.
- **База данных**: Локальная файловая БД на основе JSON-файлов в директории `/data` (пользователи, категории, промпты, история чатов), автоматически наполняемая из резервных копий `/firestore-export`.
- **ИИ-функции**: Интеграция с Google Gemini API (модель `gemini-2.5-flash-lite`) для чата с ассистентом и интеллектуального анализа изображений.

## 🖼️ Основные возможности

### 1. Макеты изображений и Кроппер

Вы можете гибко настраивать визуальное представление ваших промптов:

* **Поддерживаемые макеты (Сетки)**:
  * **1 Фото** — одиночное изображение.
  * **Слайдер ДО/ПОСЛЕ** — интерактивный ползунок для плавного сравнения двух картинок (например, генерация "до" и "после" обработки).
  * **Вертикальный сплит** — два изображения, расположенных друг над другом.
  * **Горизонтальный сплит** — два изображения, расположенных бок о бок.
  * **Сплит 1-2** — три изображения: одно крупное слева и два поменьше, сложенных вертикально справа.
  * **Сплит 2-1** — три изображения: два сверху рядом друг с другом, указывающих на одно объединенное изображение внизу.

* **Встроенный редактор-кроппер**:
  При нажатии на любую пустую ячейку макета (или кнопку «Заменить» / «Обрезать» на заполненной) открывается кастомный модальный редактор:
  * **Смещение фокуса (Pan)**: перетаскивание картинки мышкой или пальцем для выбора идеального кадра.
  * **Масштаб (Zoom)**: приближение от 100% до 300% с помощью интерактивного слайдера или кнопок.
  * **Автоматические пропорции**: рамка обрезки автоматически подстраивается под пропорции целевой ячейки выбранного макета.
  * **Canvas-рендеринг**: обрезка выполняется на клиенте с помощью HTML5 Canvas, генерируя оптимизированный Base64, который отправляется на сервер и конвертируется в файл в папке `/uploads`.

### 2. Интерактивная навигация и фильтры на главной

* **Вкладки по происхождению**: Быстрое переключение между **«Все»**, **«Мои (Авторские)»**, **«Мои (Из сети)»** и **«Чужие (Публичные)»** с динамическим подсчетом количества промптов прямо на вкладках.
* **Бейджи происхождения**: Карточки промптов содержат наглядные бейджи **«Мой»** или **«Из сети»** на изображении для мгновенного определения источника.
* **Общая панель категорий и хештегов**: Вкладки категорий (с эмодзи) и популярные хештеги объединены в горизонтальную прокручиваемую панель для мгновенной фильтрации в один клик.
* **Создание категорий на лету**: Добавлена кнопка **`+ Категория`** прямо в ленту вкладок для быстрого добавления новых категорий без необходимости открывать форму создания промпта.
* **Интерактивные хештеги на карточках**: Нажмите на любой хештег на карточке промпта, чтобы мгновенно отфильтровать всю ленту по этому тегу.

## 🛠️ Как начать работу локально?

1. **Установка зависимостей:**
   Выполните в терминале в корневой папке проекта:
   ```bash
   npm install
   ```

2. **Настройка переменных окружения:**
   Скопируйте файл `.env.example` в `.env` и добавьте свой API-ключ Gemini:
   ```bash
   cp .env.example .env
   ```
   Укажите `GEMINI_API_KEY=Ваш_Ключ` в созданном файле.

3. **Запуск в режиме разработки:**
   ```bash
   npm run dev
   ```
   Приложение запустится локально. По умолчанию сервер доступен по адресу `http://localhost:3000`.

> Обновлено: 2026-08-10
> Статус: ✅ Завершено — полноэкранное пространство, inline-редактор, подсказки, fixed IDE layout

---

## 🎯 Концепция

Клик по карточке скилла → переход на **полноэкранную страницу-пространство** (`spacedSkill` state):
- Левая панель: дерево файлов (как VS Code / GitHub)
- Правая панель: предпросмотр выбранного файла (Markdown / код) с inline-редактором (Ctrl+S / Escape)
- Шапка: название с truncate, бейджи, компактное сворачиваемое описание, панель действий в один ряд
- **Выдвижная панель подсказок** (`SkillHintsPanel`): готовые промпты для быстрого применения скилла в ИИ
- **Режим выделения**: выбор файлов/папок и скачивание их одним кастомным ZIP-архивом на лету

---

## 📸 Реализованные возможности

- **Layout**: Полноэкранный fixed IDE лейаут (`h-screen max-h-screen overflow-hidden flex flex-col`), исключающий скролл всей страницы окна
- **Шапка**: Заголовок с `truncate` и бейджами, сворачиваемое описание (`line-clamp-1` с кнопкой «Подробнее / Свернуть»), экшн-кнопки в один ряд (`flex-nowrap`)
- **SpaceFileTree**: Дерево файлов в стиле VS Code, иконки по расширениям, подсчёт файлов, чекбоксы выбора
- **SpaceFilePreview**: Просмотр Markdown / кода, breadcrumb навигация, **Inline Editor** с горячими клавишами Ctrl+S (сохранение в Supabase) и Escape
- **SkillHintsPanel**: Выдвижная панель подсказок-промптов к скиллу, копирование в 1 клик, API интеграция с таблицей `skill_hints`
- **SpaceContextMenu**: Glassmorphism меню ПКМ для файлов и папок
- **SpaceSelectionBar**: Плавающая панель снизу для выбранных файлов с подсчётом размера и генерацией ZIP (`buildSelectionZip.ts`)
